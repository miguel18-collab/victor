#  Proyecto Clases Victor
## 1. descripción del proyecto
Este proyecto contiene ejemplos y materiales de programación usados en las clases de Victor.  
Su objetivo es ayudar a practicar conceptos básicos de Git, Python y Markdown de forma sencilla.

## 2. Instrucciones de instalación
1. Descarga o clona este repositorio en tu computadora.  

2. Asegúrate de tener instalado Python 3.  

3. Abre la carpeta del proyecto en tu editor de código favorito.

## 3. Cómo ejecutar el proyecto
1. Abre tu terminal en la carpeta del proyecto.  
2. instala las librerias de matplotlib y openpyxl
    ```
    pip install openpyxl matplotlib
    ```

3.  Ejecuta el archivo principal con:  
    ```
    python bot.py
    ```
